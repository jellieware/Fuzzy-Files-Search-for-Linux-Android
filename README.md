# Fuzzy-Files-Search-for-Linux-Android
Fuzzy File Search written in C

<br><br>
Compile on Android (Termux) with:
<br><br>
clang  fast_search_android.c -o fast_search

<br><br>
Compile on Linux with:
<br><br>
clang fast_search.c -o fast_search
